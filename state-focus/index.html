State Focus: All 50 States

A verified content bank for every U.S. state. When a student joins from a new state, pull that state from here to build their State Focus lessons, the same way Florida Focus works for our Florida students.

How to use it
  1. Pick the student's state below (or search for it).
  2. Use the four ready-to-build unit plans (Grades 2–3 and Grades 4–5, Social Studies and Science) and the facts, nations, timeline and trailblazers to build the lessons.
  3. Add the finished lessons to the student's Building Blocks course as optional, self-paced State Focus lessons. Check the sources before teaching anything new.
